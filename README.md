# حكايتي

موقع حكايتي: قصص مصوّرة مخصّصة للأطفال، وطفلك هو بطل الحكاية.

رابط الموقع: https://almtbyhsn2-jpg.github.io/hikayati/

## شنو موجود بكل مجلد

- `index.html`: صفحة الموقع نفسها. لازم يضل اسمها بالإنجليزي حتى GitHub يفتحها كصفحة رئيسية.
- `الملفات/الصقر`: صور حركات صقّور (يقرأ، يباوع، فرحان).
- `الملفات/الصور`: أغلفة الحكايات وصور الأقسام.
- `الملفات/الخطوط`: خطوط مرحي وتجوال.
- `الملفات/الأصوات`: أصوات الموقع (تغريد، رفرفة، نقرات).

الأصوات من OpenGameArt وsfx-kit وKenney، كلها برخصة CC0.
